# Salary Prediction

Academic machine-learning project using an artificial neural network to predict salary in USD from structured employment data.

## Approach
- Missing-value and duplicate handling
- One-hot encoding of categorical features
- Feature standardization
- Train/test split
- Keras Sequential neural network
- RMSE and R² evaluation
- Training/validation loss visualization

## Project status
Academic / learning project. The repository preserves the original notebook workflow rather than presenting it as a production model.
